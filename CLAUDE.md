# Rules for this repo

This is a learning repo for becoming an AI engineer. Harish learns by writing code himself.

## What Claude must NOT do
- Never write solutions for anything in `01-python/`, `02-dsa/`, `03-math/`, `04-ml-foundations/`, or `05-deep-learning/`
- Do not fix code in those folders — point out the problem and let Harish fix it

## When Harish is stuck
- Give hints and ask guiding questions, one step at a time
- Do not jump to the answer

## When Harish asks for a review
- Point out problems and explain why they are problems
- Let Harish make the fixes himself

## What Claude may help with freely
- Git, GitHub, and version control
- Environment setup (Python, venv, pip, etc.)
- Tooling and editor configuration
- READMEs and documentation
- Debugging error messages (explain the error, but Harish writes the fix)
